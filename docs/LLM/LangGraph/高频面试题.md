# LangGraph 高频面试题

本文整理 LangGraph 常见面试题及参考答案。

## 一、基础概念

### 1. LangGraph 是什么？与 LangChain 的关系？

**参考答案：**

LangGraph 是 LangChain 团队开发的**基于图结构的智能体编排框架**。

与 LangChain 的关系：
- LangChain 是基础框架，提供组件封装
- LangGraph 在 LangChain 之上，用**节点 + 边 + 状态**组织工作流

**适用场景：**
- 需要多步骤的工作流（查资料 -> 整理 -> 写报告）
- 多 Agent 协作
- 需要人介入确认
- 任务中断恢复

### 2. StateGraph 和 State 是什么？Reducer 有什么用？

**参考答案：**

- **StateGraph**：节点的图，每个节点读取和写入共享的 State
- **State**：共享状态，定义图中流动的数据结构
- **Reducer**：用于聚合并行分支的更新（比如把多条消息追加到列表）

```python
class State(TypedDict):
    messages: Annotated[List[BaseMessage], add_messages]
```

### 3. 边的类型有哪些？

| 类型 | 说明 | 示例 |
|------|------|------|
| 固定边 | 顺序执行 | `add_edge("A", "B")` |
| 条件边 | 由函数路由 | `add_conditional_edges` |
| Command | 更新状态并跳转 | 支持跨图跳转 |

### 4. 消息通道有什么特别？

消息是高频场景，LangGraph 内置：
- `add_messages` reducer：智能合并/去重消息
- `RemoveMessage`：消息撤回/修订
- `MessagesState`：开箱即用的消息状态

## 二、进阶问题

### 5. Human-in-the-Loop 怎么做？interrupt 有什么用？

**参考答案：**

用 `interrupt` 在节点内暂停图执行，等待人确认后继续。

```python
# 静态打断
graph.add_node("tool", tool_node, interrupt_before=["tool"])

# 动态打断
def node(state):
    # 暂停等待
    interrupt("是否确认执行？")
```

**应用场景：**
- 工具调用审批
- 结果审核编辑
- 人工确认后继续执行

### 6. 为什么强调持久化（Checkpointer）？

**参考答案：**

编译图时接入 Checkpointer 会**每个 super-step 自动保存检查点**，支持：
- 故障恢复
- 时间旅行（回溯状态）
- 长期记忆
- 无限期挂起与恢复

```python
from langgraph.checkpoint.sqlite import SqliteSaver

checkpointer = SqliteSaver.from_conn_string(":memory:")
app = graph.compile(checkpointer=checkpointer)
```

### 7. 工具调用失败怎么处理？

**参考答案：**

- 使用 ToolNode 自动处理
- 配置重试逻辑
- 降级策略

```python
from langgraph.prebuilt import ToolNode

tool_node = ToolNode(tools, retry_on_failure=True)
```

### 8. 并行执行结果冲突怎么办？

**参考答案：**

当多个节点并行修改同一状态字段时：
- 没有定义 reducer → 后执行的覆盖先执行的
- 定义了 reducer → 按 reducer 规则合并

**解决方式：**
- 为该 key 指定 reducer（如 add_messages）
- 使用 map-reduce 模式：并行 -> 聚合

## 三、架构设计

### 9. 如何设计多 Agent 协作？

**两种模式：**

| 模式 | 说明 |
|------|------|
| Supervisor | 一个主 Agent 调度其他 Agent |
| Swarm | Agent 之间平等协作 |

```python
# Supervisor 模式
def supervisor(state):
    result = llm.invoke(state["messages"])
    if needs_research:
        return {"goto": "researcher"}
    return {"goto": "writer"}
```

### 10. 子图有什么用？

- 大图拆成可复用的子图
- 子图内部可用 Command 跳回父图
- 适合复杂协作/多代理编排

### 11. 断点续传怎么实现？

- 启用 Checkpointer
- 任务中断时状态已保存
- 重启时从上次检查点继续

## 四、高频追问

### 12. LangGraph vs 普通 DAG 区别？

| 对比 | 普通 DAG | LangGraph |
|------|----------|-----------|
| 结构 | 一往无前 | 支持反思闭环 |
| 循环 | 不支持 | 支持 cycles |
| 状态 | 无持久化 | Checkpoint |

### 13. 并发控制怎么做？

- 限制 fan-out 并发数
- 使用信号量/队列
- 分块处理

### 14. Checkpoint 选型？

| 环境 | 推荐 |
|------|------|
| 开发 | SQLite |
| 生产 | PostgreSQL |

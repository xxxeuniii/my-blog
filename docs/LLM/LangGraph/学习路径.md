## 三、第二阶段：LangGraph 核心

### 3.1 基础图结构

**学习目标**：理解 Graph 的基本概念，能创建简单的工作流

```python
from langgraph.graph import Graph

# 创建一个简单的图
graph = Graph()

# 添加节点
graph.add_node("start", start_node)
graph.add_node("end", end_node)

# 添加边
graph.add_edge("start", "end")

# 设置入口和出口
graph.set_entry_point("start")
graph.set_finish_point("end")

# 运行
result = graph.invoke(input_data)
```

### 3.2 节点定义与执行

**学习目标**：掌握节点的定义方式和执行逻辑

```python
from langgraph.graph import Graph

def my_node(state):
    # 处理逻辑
    state["output"] = "processed"
    return state

graph = Graph()
graph.add_node("my_node", my_node)
```

### 3.3 条件分支路由

**学习目标**：根据条件动态选择执行路径

```python
def router(state):
    if state["question_type"] == "math":
        return "math_node"
    elif state["question_type"] == "qa":
        return "qa_node"
    else:
        return "default_node"

graph.add_conditional_edges("router", router)
```

### 3.4 循环迭代

**学习目标**：实现循环执行逻辑

```python
def should_continue(state):
    if state["attempts"] < 3:
        return "retry"
    else:
        return "finish"

graph.add_conditional_edges("processor", should_continue, {
    "retry": "processor",
    "finish": "end"
})
```

### 3.5 人机交互

**学习目标**：实现人类在环的工作流

```python
from langgraph.graph import Graph, END

def human_review(state):
    # 等待人类审核
    user_input = input("请审核并确认：")
    state["approved"] = user_input == "确认"
    return state

graph.add_node("human_review", human_review)
graph.add_edge("human_review", END)
```

### 3.6 状态管理

**学习目标**：理解状态的传递和存储机制

```python
from typing import TypedDict

class MyState(TypedDict):
    input: str
    output: str
    intermediate_results: list

def process(state: MyState) -> MyState:
    state["intermediate_results"].append("step1")
    state["output"] = state["input"].upper()
    return state
```

## 四、第三阶段：进阶应用

### 4.1 工具调用

**学习目标**：让 Agent 能够调用外部工具

```python
from langchain.tools import Tool
from langgraph.prebuilt import ToolExecutor

tools = [
    Tool(name="search", func=search_func, description="搜索信息"),
    Tool(name="calculator", func=calculate_func, description="计算")
]

tool_executor = ToolExecutor(tools)

def tool_node(state):
    tool_result = tool_executor.invoke(state["tool_call"])
    state["tool_result"] = tool_result
    return state
```

### 4.2 多 Agent 协作

**学习目标**：实现多个 Agent 之间的协作

```python
def agent_a(state):
    # Agent A 的处理逻辑
    state["agent_a_result"] = "result from A"
    return state

def agent_b(state):
    # Agent B 的处理逻辑
    state["agent_b_result"] = "result from B"
    return state

graph.add_node("agent_a", agent_a)
graph.add_node("agent_b", agent_b)
graph.add_edge("agent_a", "agent_b")
```

### 4.3 持久化与检查点

**学习目标**：保存和恢复工作流状态

```python
from langgraph.checkpoint import MemoryCheckpoint

checkpointer = MemoryCheckpoint()
graph = Graph(checkpointer=checkpointer)

# 运行并保存状态
result = graph.invoke(input_data, config={"thread_id": "123"})

# 恢复状态继续执行
result = graph.invoke(input_data, config={"thread_id": "123"})
```

### 4.4 部署与监控

**学习目标**：将 LangGraph 应用部署到生产环境

- **API 封装**：使用 FastAPI 或 Flask 封装为 API
- **日志监控**：记录执行日志和性能指标
- **错误处理**：实现优雅的错误处理和重试机制

# 其他向量数据库

## FAISS

### 简介
FAISS (Facebook AI Similarity Search) 是 Facebook AI 开发的向量相似度搜索库，不是完整的数据库，但提供了强大的向量索引功能。

### 特点
- 性能极高
- 丰富的索引类型
- Python 和 C++ API
- 仅支持内存

### 快速开始

```python
import faiss
import numpy as np

# 创建索引
d = 1536
index = faiss.IndexFlatL2(d)

# 添加向量
vectors = np.random.random((1000, d)).astype('float32')
index.add(vectors)

# 搜索
query = np.random.random((1, d)).astype('float32')
distances, indices = index.search(query, k=5)

print(indices)
```

### 索引类型
- IndexFlatL2：暴力搜索
- IndexIVFFlat：倒排文件
- IndexHNSW：图索引
- IndexPQ：乘积量化

## Elasticsearch

### 简介
Elasticsearch 是一个分布式搜索引擎，从 8.0 版本开始支持向量搜索。

### 特点
- 功能强大的搜索引擎
- 支持向量和关键词混合搜索
- 分布式架构
- 成熟的生态

### 快速开始

```python
from elasticsearch import Elasticsearch
from elasticsearch.helpers import bulk

client = Elasticsearch("http://localhost:9200")

# 创建索引
client.indices.create(
    index="my_index",
    mappings={
        "properties": {
            "vector": {
                "type": "dense_vector",
                "dims": 1536,
                "similarity": "cosine"
            },
            "text": {"type": "text"}
        }
    }
)

# 添加文档
docs = [
    {
        "_index": "my_index",
        "_id": i,
        "_source": {
            "vector": [0.1, 0.2, 0.3],
            "text": f"文档{i}"
        }
    }
    for i in range(100)
]

bulk(client, docs)

# 搜索
result = client.search(
    index="my_index",
    query={
        "knn": {
            "field": "vector",
            "query_vector": [0.1, 0.2, 0.3],
            "k": 5,
            "num_candidates": 50
        }
    }
)

print(result)
```

## PGVector

### 简介
PGVector 是 PostgreSQL 的向量扩展，将向量搜索功能集成到关系数据库中。

### 特点
- 与 PostgreSQL 无缝集成
- 支持 SQL 查询
- 可以与关系数据联合查询
- 成熟稳定

### 快速开始

```sql
-- 安装扩展
CREATE EXTENSION vector;

-- 创建表
CREATE TABLE documents (
    id serial PRIMARY KEY,
    content text,
    embedding vector(1536)
);

-- 创建索引
CREATE INDEX ON documents USING hnsw (embedding vector_cosine_ops);

-- 插入数据
INSERT INTO documents (content, embedding)
VALUES ('文档内容', ARRAY[0.1, 0.2, 0.3, ...]::vector(1536));

-- 搜索
SELECT content, embedding <-> ARRAY[0.1, 0.2, 0.3]::vector(1536) AS distance
FROM documents
ORDER BY distance
LIMIT 5;
```

### Python 使用

```python
import psycopg2

conn = psycopg2.connect("dbname=test user=postgres")
cur = conn.cursor()

# 插入
cur.execute(
    "INSERT INTO documents (content, embedding) VALUES (%s, %s)",
    ("文档内容", [0.1, 0.2, 0.3])
)

# 搜索
cur.execute(
    "SELECT content FROM documents ORDER BY embedding <-> %s LIMIT 5",
    ([0.1, 0.2, 0.3],)
)

results = cur.fetchall()
```

## Redis Stack

### 简介
Redis Stack 支持向量搜索功能，适合缓存和低延迟场景。

### 快速开始

```python
import redis
from redis.commands.search.field import VectorField
from redis.commands.search.query import Query

r = redis.Redis(host="localhost", port=6379)

# 创建索引
r.ft().create_index([
    VectorField(
        "vector",
        "FLAT",
        {"TYPE": "FLOAT32", "DIM": 1536, "DISTANCE_METRIC": "COSINE"}
    ),
    TextField("text")
])

# 添加数据
pipeline = r.pipeline()
for i in range(100):
    pipeline.hset(f"doc:{i}", mapping={
        "vector": np.array([0.1, 0.2, 0.3]).astype(np.float32).tobytes(),
        "text": f"文档{i}"
    })
pipeline.execute()

# 搜索
query_vector = np.array([0.1, 0.2, 0.3]).astype(np.float32).tobytes()
query = (
    Query("*=>[KNN 5 @vector $vec]")
    .sort_by("__vector_score")
    .return_fields("text")
    .dialect(2)
)

results = r.ft().search(query, query_params={"vec": query_vector})
print(results)
```

## 选择建议

| 场景 | 推荐 |
|------|------|
| 已有 PostgreSQL | PGVector |
| 已有 Elasticsearch | Elasticsearch |
| 需要极高性能 | FAISS |
| 缓存场景 | Redis Stack |
| 需要完整数据库 | Milvus / Qdrant |
| 不想运维 | Pinecone / Zilliz |

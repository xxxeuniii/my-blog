# 类与对象详解

## 一、什么是面向对象编程

面向对象编程（OOP）是一种编程范式，它将数据和操作数据的方法封装在一起，形成"对象"。

**核心概念**：
- **类（Class）**：对象的模板或蓝图
- **对象（Object）**：类的实例
- **封装**：将数据和方法绑定在一起
- **继承**：从已有类创建新类
- **多态**：同一接口有不同实现

## 二、类的定义

### 2.1 基本语法

```python
class Person:
    """这是一个人类的类"""
    
    # 类属性（所有实例共享）
    species = "Human"
    
    # 构造方法
    def __init__(self, name, age):
        # 实例属性（每个实例独有）
        self.name = name
        self.age = age
    
    # 实例方法
    def greet(self):
        return f"Hello, my name is {self.name}"
    
    # 类方法
    @classmethod
    def get_species(cls):
        return cls.species
    
    # 静态方法
    @staticmethod
    def is_adult(age):
        return age >= 18
```

### 2.2 类的组成部分

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| **类属性** | 所有实例共享的属性 | `species = "Human"` |
| **实例属性** | 每个实例独有的属性 | `self.name`, `self.age` |
| **实例方法** | 需要访问实例的方法 | `def greet(self)` |
| **类方法** | 需要访问类的方法 | `@classmethod def get_species(cls)` |
| **静态方法** | 不需要访问类或实例的方法 | `@staticmethod def is_adult(age)` |

## 三、对象的创建与使用

### 3.1 创建对象（实例化）

```python
# 创建 Person 类的实例
person1 = Person("Alice", 25)
person2 = Person("Bob", 30)

# 访问实例属性
print(person1.name)  # Alice
print(person2.age)   # 30

# 调用实例方法
print(person1.greet())  # Hello, my name is Alice

# 调用类方法（可以通过类或实例调用）
print(Person.get_species())   # Human
print(person1.get_species())  # Human

# 调用静态方法（可以通过类或实例调用）
print(Person.is_adult(25))    # True
print(person1.is_adult(17))   # False
```

### 3.2 `self` 的作用

`self` 是方法的第一个参数，代表**当前对象本身**：

```python
class Person:
    def __init__(self, name):
        self.name = name  # 将参数赋值给当前对象的属性
    
    def greet(self):
        return f"Hello, {self.name}"  # 访问当前对象的属性
```

## 四、三大特性

### 4.1 封装（Encapsulation）

封装是将数据和操作数据的方法绑定在一起，隐藏内部实现细节。

```python
class BankAccount:
    def __init__(self, balance=0):
        # 使用下划线表示私有属性（约定）
        self._balance = balance
    
    def deposit(self, amount):
        if amount > 0:
            self._balance += amount
            return True
        return False
    
    def withdraw(self, amount):
        if 0 < amount <= self._balance:
            self._balance -= amount
            return True
        return False
    
    def get_balance(self):
        return self._balance

# 使用示例
account = BankAccount(1000)
account.deposit(500)
print(account.get_balance())  # 1500
account.withdraw(300)
print(account.get_balance())  # 1200
```

### 4.2 继承（Inheritance）

继承允许从已有类创建新类，新类继承父类的属性和方法。

```python
# 父类
class Animal:
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        pass

# 子类继承父类
class Dog(Animal):
    def speak(self):
        return f"{self.name} says Woof!"

class Cat(Animal):
    def speak(self):
        return f"{self.name} says Meow!"

# 使用示例
dog = Dog("Buddy")
cat = Cat("Whiskers")
print(dog.speak())  # Buddy says Woof!
print(cat.speak())  # Whiskers says Meow!
```

### 4.3 多态（Polymorphism）

多态允许同一接口有不同实现，提高代码的灵活性。

```python
def make_speak(animal):
    print(animal.speak())

dog = Dog("Buddy")
cat = Cat("Whiskers")

make_speak(dog)  # Buddy says Woof!
make_speak(cat)  # Whiskers says Meow!
```

## 五、魔术方法（特殊方法）

魔术方法以 `__` 开头和结尾，用于实现类的特殊行为。

### 5.1 常用魔术方法

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y
    
    # 加法运算
    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)
    
    # 字符串表示
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"
    
    # 长度
    def __len__(self):
        return 2
    
    # 相等比较
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

# 使用示例
v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)     # Vector(4, 6)
print(len(v1))     # 2
print(v1 == v2)    # False
```

### 5.2 常见魔术方法列表

| 方法 | 作用 |
|------|------|
| `__init__` | 构造方法，初始化对象 |
| `__repr__` | 对象的字符串表示（面向开发者） |
| `__str__` | 对象的字符串表示（面向用户） |
| `__add__` | 加法运算 `+` |
| `__sub__` | 减法运算 `-` |
| `__mul__` | 乘法运算 `*` |
| `__len__` | 长度 `len()` |
| `__eq__` | 相等比较 `==` |
| `__lt__` | 小于比较 `<` |
| `__getitem__` | 索引访问 `obj[key]` |
| `__setitem__` | 索引赋值 `obj[key] = value` |

## 六、属性访问控制

### 6.1 属性装饰器

```python
class Person:
    def __init__(self, name):
        self._name = name  # 私有属性
    
    @property
    def name(self):
        """获取属性"""
        return self._name
    
    @name.setter
    def name(self, value):
        """设置属性"""
        if not value:
            raise ValueError("Name cannot be empty")
        self._name = value
    
    @name.deleter
    def name(self):
        """删除属性"""
        del self._name

# 使用示例
person = Person("Alice")
print(person.name)     # Alice（调用 getter）
person.name = "Bob"    # 调用 setter
print(person.name)     # Bob
# del person.name      # 调用 deleter
```

### 6.2 `__slots__`

限制类的实例只能有指定的属性，节省内存。

```python
class Person:
    __slots__ = ("name", "age")  # 只允许这两个属性
    
    def __init__(self, name, age):
        self.name = name
        self.age = age

person = Person("Alice", 25)
person.name = "Bob"   # ✅ 允许
# person.city = "北京"  # ❌ 报错：Person 没有 city 属性
```

## 七、类的继承进阶

### 7.1 多重继承

```python
class Flyer:
    def fly(self):
        return "Flying..."

class Swimmer:
    def swim(self):
        return "Swimming..."

class Duck(Flyer, Swimmer):
    def quack(self):
        return "Quack!"

duck = Duck()
print(duck.fly())   # Flying...
print(duck.swim())  # Swimming...
print(duck.quack()) # Quack!
```

### 7.2 方法解析顺序（MRO）

```python
class A:
    def method(self):
        return "A"

class B(A):
    def method(self):
        return "B"

class C(A):
    def method(self):
        return "C"

class D(B, C):
    pass

d = D()
print(d.method())        # B
print(D.__mro__)         # (<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>)
```

## 八、设计模式

### 8.1 单例模式

确保类只有一个实例。

```python
class Singleton:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

s1 = Singleton()
s2 = Singleton()
print(s1 is s2)  # True
```

### 8.2 工厂模式

封装对象的创建过程。

```python
class Dog:
    def speak(self):
        return "Woof!"

class Cat:
    def speak(self):
        return "Meow!"

class AnimalFactory:
    @staticmethod
    def create_animal(animal_type):
        if animal_type == "dog":
            return Dog()
        elif animal_type == "cat":
            return Cat()
        else:
            raise ValueError("Unknown animal type")

factory = AnimalFactory()
dog = factory.create_animal("dog")
print(dog.speak())  # Woof!
```

## 九、实战案例：图书管理系统

```python
class Book:
    def __init__(self, title, author, isbn):
        self.title = title
        self.author = author
        self.isbn = isbn
        self.available = True
    
    def __repr__(self):
        status = "Available" if self.available else "Borrowed"
        return f"Book({self.title}, {self.author}, {status})"

class Library:
    def __init__(self):
        self.books = []
    
    def add_book(self, book):
        self.books.append(book)
    
    def find_book(self, isbn):
        for book in self.books:
            if book.isbn == isbn:
                return book
        return None
    
    def borrow_book(self, isbn):
        book = self.find_book(isbn)
        if book and book.available:
            book.available = False
            return True
        return False
    
    def return_book(self, isbn):
        book = self.find_book(isbn)
        if book and not book.available:
            book.available = True
            return True
        return False

# 使用示例
library = Library()
library.add_book(Book("Python编程", "Guido", "12345"))
library.add_book(Book("Java编程", "James", "67890"))

print(library.borrow_book("12345"))  # True
print(library.borrow_book("12345"))  # False（已借出）
print(library.return_book("12345"))  # True
```

## 十、总结

| 概念 | 说明 |
|------|------|
| **类** | 对象的模板，定义属性和方法 |
| **对象** | 类的实例，拥有具体的属性值 |
| **封装** | 隐藏内部实现，通过方法访问数据 |
| **继承** | 从父类继承属性和方法 |
| **多态** | 同一接口有不同实现 |
| **魔术方法** | 实现类的特殊行为 |

**核心要点**：
1. 类是模板，对象是实例
2. `self` 代表当前对象
3. 通过继承实现代码复用
4. 通过多态实现灵活的接口设计

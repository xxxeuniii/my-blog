# 样式污染治理

样式污染是指不同组件或页面之间的 CSS 样式相互影响，导致页面显示异常。

## 一、什么是样式污染

### 污染场景

```css
/* 全局样式 */
.button { padding: 10px; }
.title { font-size: 20px; }

/* 组件A */
.button { background: blue; }

/* 组件B */
.button { background: red; }

/* 结果：后面的样式会覆盖前面的 */
```

### 污染后果

- 组件样式互相影响
- 页面显示异常
- 难以维护和排查问题

## 二、CSS Modules

### 原理

通过生成唯一的类名，实现样式隔离。

```css
/* Button.module.css */
.button {
  background: blue;
  color: white;
}
```

```javascript
import styles from './Button.module.css'

export default function Button() {
  return (
    <button className={styles.button}>
      点击
    </button>
  )
}
```

### 编译后

```html
<button class="Button_button_abc123">
  点击
</button>
```

### Vue 中使用

```vue
<template>
  <button :class="$style.button">
    点击
  </button>
</template>

<style module>
.button {
  background: blue;
}
</style>
```

## 三、Scoped CSS

### Vue Scoped

```vue
<template>
  <button class="btn">点击</button>
</template>

<style scoped>
.btn {
  background: blue;
}
</style>
```

### 原理

```css
/* 编译后自动添加唯一属性 */
.btn[data-v-abc123] {
  background: blue;
}
```

```html
<button class="btn" data-v-abc123>
  点击
</button>
```

## 四、CSS-in-JS

### Styled Components

```javascript
import styled from 'styled-components'

const Button = styled.button`
  background: blue;
  color: white;
  padding: 10px 20px;
  
  &:hover {
    background: darkblue;
  }
`

function App() {
  return <Button>点击</Button>
}
```

### Emotion

```javascript
/** @jsxImportSource @emotion/react */
import { css } from '@emotion/react'

const buttonStyle = css`
  background: blue;
  color: white;
`

function App() {
  return <button css={buttonStyle}>点击</button>
}
```

## 五、Tailwind CSS

### 原理

通过工具类组合，避免全局样式污染。

```html
<!-- 不需要写自定义 CSS -->
<button class="bg-blue-500 text-white px-4 py-2 rounded">
  点击
</button>
```

### 配置

```javascript
// tailwind.config.js
module.exports = {
  content: ['./src/**/*.{vue,js,ts,jsx,tsx}'],
  theme: {
    extend: {
      colors: {
        primary: '#007bff'
      }
    }
  },
  plugins: []
}
```

## 六、BEM 命名规范

### 命名规则

```
Block__Element--Modifier
```

### 示例

```css
/* Block */
.card { }

/* Element */
.card__title { }
.card__content { }

/* Modifier */
.card--large { }
.card__title--highlight { }
```

### HTML 使用

```html
<div class="card card--large">
  <h2 class="card__title card__title--highlight">标题</h2>
  <div class="card__content">内容</div>
</div>
```

## 七、动态作用域

### CSS 变量

```css
:root {
  --primary-color: blue;
  --font-size: 14px;
}

.component {
  color: var(--primary-color);
  font-size: var(--font-size);
}
```

### 运行时切换主题

```javascript
// 切换主题
document.documentElement.setAttribute('data-theme', 'dark')

/* 主题样式 */
[data-theme="dark"] {
  --bg-color: #1a1a1a;
  --text-color: #fff;
}
```

## 八、Shadow DOM

### 使用

```javascript
const shadow = element.attachShadow({ mode: 'open' })
shadow.innerHTML = `
  <style>
    button {
      background: blue;
    color: white;
    }
  </style>
  <button>点击</button>
`
```

### 特点

- 样式完全隔离
- 不受外部 CSS 影响
- 不影响外部样式

## 九、最佳实践

### 1. 避免全局样式

```css
/* 不好 */
.button { }

/* 好 */
.btn-primary { }
.btn-secondary { }
```

### 2. 使用 CSS 前缀

```css
/* 添加项目前缀 */
.myproject-btn { }
.myproject-card { }
```

### 3. 组件化样式

```css
/* 每个组件独立的 CSS 文件 */
Button.css
Card.css
Modal.css
```

### 4. 样式检查工具

```bash
# stylelint
npx stylelint "**/*.css"
```

## 十、方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| CSS Modules | 简单，自动生成唯一类名 | 需要配置 |
| Scoped CSS | Vue 原生支持 | 仅 Vue |
| CSS-in-JS | 样式 JS 管理 | 运行时开销 |
| Tailwind | 原子化，无需写 CSS | 学习成本 |
| BEM | 简单，不需工具 | 命名复杂 |

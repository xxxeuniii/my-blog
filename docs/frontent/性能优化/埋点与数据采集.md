# 埋点与数据采集

埋点是通过在应用中采集用户行为数据，用于分析用户行为和产品优化。

## 一、埋点类型

### 1. 页面埋点

```javascript
// 页面浏览
track('page_view', {
  page_name: '首页',
  page_path: '/',
  referrer: document.referrer
})
```

### 2. 交互埋点

```javascript
// 按钮点击
track('button_click', {
  button_name: '立即购买',
  button_id: 'btn-buy-now',
  page: '/product/123'
})

// 表单提交
track('form_submit', {
  form_name: '用户登录',
  form_id: 'login-form',
  success: true
})
```

### 3. 性能埋点

```javascript
// 页面加载时间
track('page_load', {
  load_time: 1234,
  ttfb: 456,
  fcp: 789
})

// 接口耗时
track('api_performance', {
  api: '/api/user',
  duration: 234,
  status: 200
})
```

### 4. 错误埋点

```javascript
// JS 错误
track('js_error', {
  message: error.message,
  stack: error.stack,
  filename: error.filename,
  lineno: error.lineno
})

// 接口错误
track('api_error', {
  api: '/api/user',
  status: 500,
  message: 'Internal Server Error'
})
```

## 二、埋点方案

### 1. 手动埋点

```javascript
// 在需要的地方手动调用
<button onClick={() => {
  track('button_click', { button: 'buy' })
  handleBuy()
}}>购买</button>
```

### 2. 自动埋点

```javascript
// 自动监听点击事件
document.addEventListener('click', (e) => {
  const target = e.target
  if (target.matches('[data-track]')) {
    track(target.dataset.track, JSON.parse(target.dataset.trackData || '{}'))
  }
})
```

```html
<!-- 使用 data 属性 -->
<button data-track="button_click" data-track-data='{"button": "buy"}'>
  购买
</button>
```

### 3. 路由变化埋点

```javascript
// Vue 路由守卫
router.afterEach((to) => {
  track('page_view', {
    page_name: to.name,
    page_path: to.path
  })
})

// React 路由变化
useEffect(() => {
  track('page_view', {
    page_name: location.pathname,
    page_path: location.pathname
  })
}, [location.pathname])
```

## 三、上报方式

### 1. Navigator.sendBeacon

```javascript
// 推荐方式，页面关闭时也会发送
function track(event, data) {
  const payload = JSON.stringify({
    event,
    data,
    timestamp: Date.now(),
    user_id: getUserId(),
    session_id: getSessionId()
  })

  navigator.sendBeacon('/api/track', payload)
}
```

### 2. Image 上报

```javascript
// 兼容性好，支持 GIF 上报
function trackByImage(event, data) {
  const img = new Image()
  const params = new URLSearchParams({
    event,
    data: JSON.stringify(data),
    t: Date.now()
  })
  img.src = `/api/track.gif?${params}`
}
```

### 3. fetch 上报

```javascript
async function track(event, data) {
  try {
    await fetch('/api/track', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ event, data })
    })
  } catch (e) {
    console.error('埋点上报失败', e)
  }
}
```

## 四、批量上报

```javascript
const queue = []

function addToQueue(event, data) {
  queue.push({ event, data, timestamp: Date.now() })

  // 达到批量数量时上报
  if (queue.length >= 10) {
    flush()
  }
}

function flush() {
  if (queue.length === 0) return

  navigator.sendBeacon('/api/track/batch', JSON.stringify(queue))
  queue.length = 0
}

// 页面离开时上报
window.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'hidden') {
    flush()
  }
})
```

## 五、隐私与合规

### 1. 用户授权

```javascript
// 检查是否同意埋点
function canTrack() {
  return localStorage.getItem('consent') === 'true'
}

function track(event, data) {
  if (!canTrack()) return
  // 上报
}
```

### 2. 数据脱敏

```javascript
function sanitize(data) {
  const sanitized = { ...data }
  // 移除敏感信息
  delete sanitized.phone
  delete sanitized.idCard
  // 部分掩码
  sanitized.email = maskEmail(sanitized.email)
  return sanitized
}

function maskEmail(email) {
  if (!email) return ''
  const [name, domain] = email.split('@')
  return name[0] + '***@' + domain
}
```

## 七、最佳实践

### 1. 埋点规范

```javascript
// 统一埋点格式
{
  event: 'button_click',      // 事件名称
  data: {                     // 事件数据
    button: 'buy',
    page: '/product'
  },
  timestamp: 1700000000000,    // 时间戳
  user_id: 'user123',         // 用户 ID
  session_id: 'session456',   // 会话 ID
  device: 'pc',              // 设备类型
  platform: 'web'             // 平台
}
```

### 2. 避免过度埋点

```javascript
// 只埋点关键行为
// 好：关键转化节点
track('purchase_complete', { amount: 99 })

// 不好：所有点击都埋点
track('any_click', { element: 'div' })
```

## 八、常见问题

### 1. 上报失败

- 使用 sendBeacon 保证页面关闭时也能上报
- 添加重试机制
- 失败时存入本地，后续补报

### 2. 数据丢失

- 使用批量上报减少请求
- 页面离开时强制上报
- 本地缓存未上报数据

### 3. 性能影响

- 异步上报，不阻塞主线程
- 批量上报减少请求数
- 合理选择上报时机

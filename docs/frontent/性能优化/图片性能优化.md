# 图片性能优化

图片通常是网页中最大的资源，优化图片可以大幅提升加载性能。

## 一、图片格式选择

### 格式对比

| 格式 | 特点 | 适用场景 |
|------|------|----------|
| JPEG | 有损压缩，体积小 | 照片、复杂图像 |
| PNG | 无损透明 | 图标、Logo、需要透明 |
| WebP | 压缩率比 JPEG/PNG 高 25-35% | 现代浏览器 |
| SVG | 矢量，体积小 | 图标、Icon |
| GIF | 动画 | 简单动画 |

### 格式选择建议

```html
<!-- 照片用 JPEG/WebP -->
<img src="photo.jpg" alt="照片">

<!-- 需要透明用 PNG/WebP -->
<img src="logo.png" alt="Logo">

<!-- 图标用 SVG -->
<img src="icon.svg" alt="Icon">

<!-- 动画用 GIF -->
<img src="animation.gif" alt="动画">
```

## 二、WebP 格式

### 1. 浏览器支持

```html
<picture>
  <source srcset="image.webp" type="image/webp">
  <img src="image.jpg" alt="图片">
</picture>
```

### 2. 转换工具

```javascript
// sharp
const sharp = require('sharp')
sharp('input.jpg')
  .webp({ quality: 80 })
  .toFile('output.webp')

// imagemin
const imagemin = require('imagemin')
const webp = require('imagemin-webp')

imagemin(['input.jpg'], {
  plugins: [webp({ quality: 80 })]
})
```

## 三、响应式图片

### 1. srcset

```html
<img srcset="image-320.jpg 320w,
             image-640.jpg 640w,
             image-1024.jpg 1024w"
     sizes="(max-width: 480px) 280px,
            (max-width: 960px) 580px,
            980px"
     src="image-640.jpg"
     alt="响应式图片">
```

### 2. sizes

```html
<!-- 视口宽度 <= 600px 时，占用 100vw -->
<!-- 视口宽度 > 600px 时，占用 50vw -->
<img srcset="small.jpg 500w, large.jpg 1000w"
     sizes="(max-width: 600px) 100vw, 50vw"
     src="small.jpg"
     alt="图片">
```

### 3. picture 元素

```html
<picture>
  <!-- 移动端 -->
  <source media="(max-width: 600px)" srcset="mobile.jpg">
  <!-- 平板 -->
  <source media="(max-width: 960px)" srcset="tablet.jpg">
  <!-- 桌面 -->
  <source srcset="desktop.jpg">
  <!-- 默认 -->
  <img src="desktop.jpg" alt="图片">
</picture>
```

## 四、图片懒加载

### 1. 浏览器原生支持

```html
<img loading="lazy" src="image.jpg" alt="懒加载图片">
```

### 2. Intersection Observer

```javascript
// 检测图片是否进入视口
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target
      img.src = img.dataset.src
      img.classList.remove('lazy')
      observer.unobserve(img)
    }
  })
}, { rootMargin: '50px' })

// 使用
document.querySelectorAll('img.lazy').forEach(img => {
  observer.observe(img)
})
```

### 3. Vue 懒加载指令

```javascript
// v-lazy 指令
Vue.directive('lazy', {
  inserted: (el) => {
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          el.src = el.dataset.src
          observer.unobserve(el)
        }
      })
    })
    observer.observe(el)
  }
})

// 使用
<img v-lazy data-src="image.jpg">
```

### 4. React 懒加载组件

```javascript
import { LazyImage } from 'react-lazy-loading'

function App() {
  return (
    <LazyImage src="image.jpg" placeholder="placeholder.jpg" />
  )
}
```

## 五、图片压缩

### 1. 有损压缩

```javascript
// JPEG 压缩
sharp('input.jpg')
  .jpeg({ quality: 80 })
  .toFile('output.jpg')

// WebP 有损
sharp('input.jpg')
  .webp({ quality: 80 })
  .toFile('output.webp')
```

### 2. 无损压缩

```javascript
// PNG 无损
sharp('input.png')
  .png({ compressionLevel: 9 })
  .toFile('output.png')
```

### 3. 命令行工具

```bash
# imagemin
imagemin input.jpg --outpu-dir=output

# pngquant
pngquant --quality=65-80 input.png -o output.png
```

## 六、CSS 背景图片

### 1. 响应式背景图

```css
/* 移动端 */
.bg-image {
  background-image: url('mobile.jpg');
}

/* 桌面端 */
@media (min-width: 960px) {
  .bg-image {
    background-image: url('desktop.jpg');
  }
}
```

### 2. Base64 编码

```css
/* 小图标可以转 Base64，减少请求 */
.icon {
  background-image: url('data:image/svg+xml;base64,...');
}
```

## 七、图片 CDN

### 1. 使用 CDN

```html
<img src="https://cdn.example.com/image.jpg">
```

### 2. CDN 参数

```html
<!-- 指定尺寸 -->
<img src="https://cdn.example.com/image.jpg?w=300&h=200">

<!-- 指定格式 -->
<img src="https://cdn.example.com/image.jpg?format=webp">

<!-- 指定质量 -->
<img src="https://cdn.example.com/image.jpg?quality=80">
```

## 十、缓存策略

```nginx
# 图片长期缓存

  add_header Cache-Control "public, max-age=2592000";
}
```

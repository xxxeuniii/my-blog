# 渲染性能优化

渲染性能优化主要关注页面加载后的交互流畅度。

## 一、减少重排重绘

### 1. 什么是重排重绘

| 概念 | 说明 |
|------|------|
| 重排（Reflow） | 元素位置、尺寸改变，浏览器重新布局 |
| 重绘（Repaint） | 元素样式改变，浏览器重新绘制 |

### 2. 触发重排的操作

```javascript
// 这些操作会触发重排
element.style.width = '100px'
element.style.height = '100px'
element.style.margin = '10px'
element.style.padding = '10px'
element.style.display = 'none'
element.offsetLeft // 读取布局属性会触发
```

### 3. 优化技巧

```javascript
// 不好 - 多次修改
element.style.width = '100px'
element.style.height = '100px'
element.style.color = 'red'

// 好 - 一次性修改
element.style.cssText = 'width: 100px; height: 100px; color: red'

// 好 - 使用 class
element.classList.add('active')
```

## 二、使用 CSS Transform

```javascript
// 不好 - 触发布局
element.style.top = (x + 10) + 'px'
element.style.left = (y + 10) + 'px'

// 好 - 仅重绘
element.style.transform = 'translate(10px, 10px)'

// 好 - 使用 translate3d 开启硬件加速
element.style.transform = 'translate3d(10px, 10px, 0)'
```

## 三、虚拟列表

### 1. 场景

渲染成千上万条数据时，一次性渲染所有 DOM 会很慢。

### 2. Vue 虚拟列表

```html
<template>
  <virtual-list
    :items="items"
    :item-size="50"
    height="400px"
  >
    <template #item="{ item }">
      <div>{{ item.name }}</div>
    </template>
  </virtual-list>
</template>
```

### 3. React 虚拟列表

```javascript
import { FixedSizeList } from 'react-window'

const Row = ({ index, style }) => (
  <div style={style}>Row {index}</div>
)

function App() {
  return (
    <FixedSizeList
      height={400}
      itemCount={1000}
      itemSize={50}
      width={300}
    >
      {Row}
    </FixedSizeList>
  )
}
```

## 四、Web Worker

### 1. 场景

复杂计算会阻塞主线程，影响页面响应。

### 2. 使用 Web Worker

```javascript
// worker.js
self.onmessage = (e) => {
  const result = heavyComputation(e.data)
  self.postMessage(result)
}

// main.js
const worker = new Worker('worker.js')
worker.postMessage({ data: [1, 2, 3] })
worker.onmessage = (e) => {
  console.log('Result:', e.data)
}
```

### 3. 共享 Worker

```javascript
const worker = new SharedWorker('worker.js')
worker.port.postMessage({ data: 'hello' })
```

## 五、防抖节流

### 1. 防抖 - Debounce

等待一段时间后执行，如果这期间再次触发，则重新计时。

```javascript
function debounce(fn, delay) {
  let timer
  return function(...args) {
    clearTimeout(timer)
    timer = setTimeout(() => fn.apply(this, args), delay)
  }
}

// 使用
window.addEventListener('resize', debounce(handleResize, 200))
```

### 2. 节流 - Throttle

固定时间内只执行一次。

```javascript
function throttle(fn, delay) {
  let last = 0
  return function(...args) {
    const now = Date.now()
    if (now - last > delay) {
      last = now
      fn.apply(this, args)
    }
  }
}

// 使用
window.addEventListener('scroll', throttle(handleScroll, 100))
```

## 六、requestAnimationFrame

### 1. 使用场景

动画制作，确保在下一帧执行。

```javascript
// 不好的写法
function animate() {
  element.style.left = position + 'px'
  position += 1
  setTimeout(animate, 16)
}

// 好的写法
function animate() {
  element.style.transform = `translateX(${position}px)`
  position += 1
  requestAnimationFrame(animate)
}
requestAnimationFrame(animate)
```

### 2. 动画优化示例

```javascript
function animateElements() {
  const elements = document.querySelectorAll('.animate-me')
  elements.forEach((el, index) => {
    el.style.transform = `translateY(${index * 10}px)`
  })
  requestAnimationFrame(animateElements)
}
```

## 七、DocumentFragment

### 1. 批量 DOM 操作

```javascript
// 不好 - 每次插入都触发重排
const list = document.getElementById('list')
for (let i = 0; i < 1000; i++) {
  const item = document.createElement('div')
  item.textContent = i
  list.appendChild(item)
}

// 好 - 使用 DocumentFragment
const fragment = document.createDocumentFragment()
for (let i = 0; i < 1000; i++) {
  const item = document.createElement('div')
  item.textContent = i
  fragment.appendChild(item)
}
list.appendChild(fragment)
```

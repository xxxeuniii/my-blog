# 国内云平台概览

国内云平台适合主要用户位于中国大陆、需要本地化服务支持，或需要满足备案与行业合规要求的业务。

## 主流平台

| 云平台 | 常见优势 | 典型场景 |
| --- | --- | --- |
| 阿里云 | 产品体系完整，电商与互联网生态成熟 | Web 应用、数据平台、电商业务 |
| 腾讯云 | 音视频、游戏、社交生态能力突出 | 音视频、游戏、微信生态应用 |
| 华为云 | 政企、制造与混合云能力较强 | 政企系统、工业互联网、混合云 |
| 火山引擎 | 数据分析、内容与增长工具丰富 | 内容平台、推荐系统、数据增长 |
| 百度智能云 | AI 与行业解决方案较丰富 | AI 应用、搜索、智能客服 |

## 核心服务类型

| 能力 | 常见产品类型 |
| --- | --- |
| 计算 | 云服务器、裸金属、容器服务、Serverless |
| 网络 | VPC、负载均衡、NAT 网关、CDN、DNS |
| 存储 | 对象存储、云硬盘、文件存储、归档存储 |
| 数据库 | 云数据库、缓存、数据仓库、数据湖 |
| 安全 | WAF、DDoS 防护、密钥管理、云防火墙 |
| 运维 | 日志服务、监控告警、链路追踪、自动化部署 |

## 选型重点

1. **地域与网络**：确认用户分布、可用区覆盖、跨地域延迟与公网带宽成本。
2. **备案与合规**：中国大陆公网网站通常需要完成 ICP 备案，并关注等保与数据合规要求。
3. **产品匹配度**：优先选择团队熟悉且托管服务成熟的平台，减少自行运维成本。
4. **成本结构**：同时评估计算、存储、流量、快照、日志和跨地域传输费用。
5. **可迁移性**：使用容器、Terraform 和标准数据库协议，降低平台锁定风险。

## 常见基础架构

```text
用户请求
  → CDN / DNS
  → WAF / 负载均衡
  → 云服务器或容器集群
  → 云数据库与缓存
  → 对象存储
  → 日志、监控与告警
```

## 上线检查

- 使用多个可用区部署关键服务
- 为数据库、对象存储和云硬盘配置备份策略
- 限制安全组端口并启用最小权限访问
- 配置资源监控、费用告警和异常登录告警
- 对域名、证书、备案和到期时间建立台账

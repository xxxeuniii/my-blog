# 网络层安全防护

## 一、防火墙配置

### 1.1 iptables（Linux）

```bash
# 允许回环接口
iptables -A INPUT -i lo -j ACCEPT

# 允许已建立的连接
iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许SSH连接（端口22）
iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许HTTP（80）和HTTPS（443）
iptables -A INPUT -p tcp --dport 80 -j ACCEPT
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 拒绝所有其他入站连接
iptables -P INPUT DROP

# 保存规则
iptables-save > /etc/iptables/rules.v4
```

### 1.2 firewalld（CentOS/RHEL）

```bash
# 启动并启用firewalld
systemctl start firewalld
systemctl enable firewalld

# 允许服务
firewall-cmd --add-service=http --permanent
firewall-cmd --add-service=https --permanent
firewall-cmd --add-service=ssh --permanent

# 允许特定端口
firewall-cmd --add-port=8080/tcp --permanent

# 重新加载配置
firewall-cmd --reload
```

## 二、安全组配置（云服务器）

```yaml
# 阿里云安全组规则示例
rules:
  - ip_protocol: tcp
    port_range: "22/22"
    source_cidr_ip: "192.168.1.0/24"  # 限制特定IP段访问SSH
    policy: accept
  
  - ip_protocol: tcp
    port_range: "80/80"
    source_cidr_ip: "0.0.0.0/0"        # 允许所有IP访问HTTP
    policy: accept
  
  - ip_protocol: tcp
    port_range: "443/443"
    source_cidr_ip: "0.0.0.0/0"        # 允许所有IP访问HTTPS
    policy: accept
```

## 三、DDoS防护

### 3.1 使用 fail2ban

```bash
# 安装并配置 fail2ban
apt-get install fail2ban -y

# 配置SSH防护
cat > /etc/fail2ban/jail.local << EOF
[sshd]
enabled = true
port = ssh
filter = sshd
logpath = /var/log/auth.log
maxretry = 3
bantime = 3600
EOF

systemctl restart fail2ban
systemctl enable fail2ban
```

### 3.2 配置额外防护规则

```bash
# 限制单IP每秒最大连接数
iptables -A INPUT -p tcp --syn --dport 80 -m limit --limit 1/s --limit-burst 3 -j ACCEPT

# 防止SYN洪水攻击
iptables -A INPUT -p tcp --syn -m limit --limit 1/s -j ACCEPT
```

## 四、端口安全

### 4.1 查看开放端口

```bash
# 查看所有监听端口
netstat -tlnp

# 仅查看TCP端口
ss -tlnp
```

### 4.2 关闭不必要的端口

```bash
# 查找并关闭服务
systemctl disable --now rpcbind
systemctl disable --now avahi-daemon
```

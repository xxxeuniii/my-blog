# If-I-Held - 如果当时没有卖

## 项目简介

[If-I-Held](https://github.com/xxxeuniii/If-I-Held) 是一个轻量、有趣的股票复盘工具。用户输入曾经卖出的股票、数量和价格，应用会获取当前行情，并计算“如果当时没有卖出，现在会怎样”。

与传统收益计算器不同，项目不仅展示收益差额和收益率，还会生成带有情绪色彩的复盘文案，并将机会成本换算成奶茶、电影票、iPhone、PS5 或旅行天数等更直观的生活消费。

**在线体验**：[https://if-i-held.vercel.app/](https://if-i-held.vercel.app/)

**核心流程**：

```text
输入股票代码、卖出数量与卖出价格
    ↓
从东方财富获取当前行情
    ↓
计算持有至今的价值、收益差额与收益率
    ↓
生成情绪文案和机会成本对比
    ↓
将复盘结果导出为图片
```

> 项目仅用于娱乐和投资复盘，不构成任何投资建议。

## 核心功能

### 股票复盘计算

输入股票代码、卖出数量和卖出价格后，应用会获取股票当前价格，并计算如果一直持有到现在的总价值、收益差额与收益率。

### 支持 A 股与美股

项目支持输入 6 位 A 股代码和美股代码，并根据股票市场展示对应的人民币或美元符号。

### 今日行情展示

除了复盘结果，页面还会展示当前价格，以及今日开盘价、收盘价、最高价和最低价等行情数据。

### 情绪文案

应用会根据收益率区间生成不同级别的情绪文案，让原本偏严肃的收益计算更有趣，也更适合作为复盘结果分享。

### 机会成本对比

收益差额会被转换为更容易理解的生活场景，例如可以买多少杯奶茶、多少张电影票、多少台 iPhone，或可以旅行多少天。

### 结果图片导出

通过 html2canvas 将复盘结果卡片转换为 PNG 图片，方便保存和分享。

## 页面布局

页面采用三列卡片结构，将输入、行情和结果明确分区：

| 区域 | 内容 |
|------|------|
| 左列 | 股票代码、卖出数量、卖出价格或日期 |
| 中列 | 当前价格与今日行情 |
| 右列 | 收益差额、收益率、情绪文案和机会成本 |

这种布局让用户可以在同一屏完成输入、查看行情和理解复盘结果。

## 工作原理

```text
用户提交复盘信息
    │
    ├── 格式化股票代码
    ├── 将股票代码转换为东方财富 secid
    ├── 请求东方财富当前行情
    ├── 请求失败时使用兜底行情
    ├── 根据价格、数量计算收益差额
    ├── 根据收益率选择情绪文案
    ├── 随机选择机会成本对比项
    └── 使用 html2canvas 导出结果卡片
```

当前版本直接从浏览器请求东方财富公开行情接口，无需额外后端或 CORS 代理：

```text
https://push2.eastmoney.com/api/qt/stock/get
```

股票代码会先转换成东方财富使用的 `secid`。例如上交所使用 `1.股票代码`，深交所使用 `0.股票代码`，美股则根据交易所使用 `105`、`106` 或 `107`。请求失败或返回数据异常时，部分常见股票会使用内置兜底数据。

## 核心计算

假设卖出数量为 `quantity`，卖出价格为 `soldPrice`，当前价格为 `currentPrice`：

```text
当时卖出价值 = quantity × soldPrice
持有至今价值 = quantity × currentPrice
收益差额 = 持有至今价值 - 当时卖出价值
收益率 = 收益差额 ÷ 当时卖出价值 × 100%
```

收益差额为正数时，表示错过了一部分上涨收益；为负数时，则说明当时卖出避免了后续亏损。

## 项目特点

1. **输入简单直接**：输入股票代码、卖出数量和卖出价格即可完成复盘
2. **复盘结果直观**：同时展示收益差额、收益率和行情数据
3. **表达方式有趣**：使用情绪文案和生活消费对比解释机会成本
4. **支持结果分享**：可以将复盘结果卡片导出为图片
5. **具备兜底机制**：行情请求失败时仍可使用兜底数据体验功能
6. **部署简单**：纯前端应用，无需自建后端服务

---

## 当前限制与演进方向

- 股票代码目前仅支持手动输入，可以增加搜索与自动补全
- 东方财富公开接口可能调整、限流或暂时不可用
- 可以增加复权价格、手续费、分红和汇率等更完整的计算因素
- 可以加入多次买卖记录与持仓组合复盘
- 可以增加收益曲线和基准指数对比
- 可以将行情请求迁移到自有后端或 Serverless API

代码性能优化 ​

代码性能优化关注如何编写更高效的 JavaScript 代码。

一、Tree Shaking ​

1. 什么是 Tree Shaking ​

Tree Shaking 是打包时移除未使用的代码。

2. 条件 ​

javascript
// ES Module 才会 Tree Shaking
import { add } from './math'

add(1, 2)  // 会被保留
subtract(1, 2)  // 会被移除

3. sideEffects ​

json
// package.json
{
  "sideEffects": [
    "*.css",
    "*.scss"
  ]
}

二、Code Splitting ​

1. 路由级分割 ​

javascript
// Vue
const routes = [
  { path: '/', component: () => import('./Home.vue') },
  { path: '/about', component: () => import('./About.vue') }
]

// React
const Home = lazy(() => import('./Home'))
const About = lazy(() => import('./About'))

2. 组件级分割 ​

javascript
// Vue
const HeavyChart = defineAsyncComponent(() => import('./HeavyChart.vue'))

// React
const HeavyChart = lazy(() => import('./HeavyChart'))

3. 动态 import ​

javascript
// 点击时再加载
button.addEventListener('click', async () => {
  const { heavyFunction } = await import('./heavy.js')
  heavyFunction()
})

三、减少循环中的操作 ​

javascript
// 不好 - 每次迭代都访问属性
for (let i = 0; i < arr.length; i++) {
  // arr.length 每次都计算
}

// 好 - 缓存长度
for (let i = 0, len = arr.length; i < len; i++) {
  // ...
}

四、对象优化 ​

1. 对象创建 ​

javascript
// 不好
const obj = new Object()
obj.name = 'Tom'
obj.age = 20

// 好
const obj = { name: 'Tom', age: 20 }

2. 对象查询 ​

javascript
// 不好 - 多次点号访问
const city = user.address.city

// 好 - 解构
const { address: { city } } = user

// 好 - 缓存中间值
const address = user && user.address
const city = address && address.city

五、数组优化 ​

1. 数组方法选择 ​

javascript
// 遍历 - 用 forEach/map/filter
arr.forEach(v => console.log(v))
arr.map(v => v * 2)
arr.filter(v => v > 5)

// 查找 - 用 find/findIndex
arr.find(v => v.id === 1)
arr.findIndex(v => v.id === 1)

// 判断 - 用 some/every
arr.some(v => v > 5)
arr.every(v => v > 0)

// 聚合 - 用 reduce
arr.reduce((sum, v) => sum + v, 0)

2. 避免在循环中修改数组 ​

javascript
// 不好
for (let i = 0; i < arr.length; i++) {
  arr.push(arr[i] * 2)
}

// 好
const newArr = arr.map(v => v * 2)

六、函数优化 ​

1. 函数缓存 ​

javascript
// 简单缓存
const cache = {}
function expensive(arg) {
  if (cache[arg]) return cache[arg]
  const result = compute(arg)
  cache[arg] = result
  return result
}

// 使用 memoization
function memoize(fn) {
  const cache = {}
  return function(...args) {
    const key = JSON.stringify(args)
    if (cache[key]) return cache[key]
    return cache[key] = fn.apply(this, args)
  }
}

2. 函数组合 ​

javascript
// 组合函数
const compose = (...fns) => x => fns.reduceRight((v, f) => f(v), x)
const pipe = (...fns) => x => fns.reduce((v, f) => f(v), x)

// 使用
const process = pipe(trim, toLowerCase, capitalize)
process('  HELLO  ') // 'Hello'

七、异步优化 ​

1. 并行执行 ​

javascript
// 不好 - 串行
const user = await fetchUser()
const posts = await fetchPosts()

// 好 - 并行
const [user, posts] = await Promise.all([
  fetchUser(),
  fetchPosts()
])

2. 避免 await 在循环中 ​

javascript
// 不好
for (const id of ids) {
  const data = await fetch(id)
}

// 好 - Promise.all
const results = await Promise.all(ids.map(id => fetch(id)))

八、事件委托 ​

javascript
// 不好 - 每个子元素绑定事件
items.forEach(item => {
  item.addEventListener('click', handleClick)
})

// 好 - 事件委托到父元素
list.addEventListener('click', (e) => {
  if (e.target.matches('.item')) {
    handleClick(e)
  }
})

九、使用 Map/Set ​

javascript
// Map 比 Object 快，尤其是频繁增删时
const map = new Map()
map.set('key', 'value')
map.get('key')

// Set 去重，比 array.filter 快
const unique = [...new Set(array)]

性能监控 ​

性能监控用于实时检测和追踪页面性能，及时发现和解决性能问题。

一、Web Vitals 核心指标 ​

1. LCP (Largest Contentful Paint) ​

最大内容绘制时间，表示页面最大元素加载完成的时间。

javascript
import { getLCP } from 'web-vitals'

getLCP(console.log)

// 输出示例
{
  name: 'LCP',
  value: 1254.2,
  rating: 'needs-improvement',
  id: 'vital-1'
}

2. FID (First Input Delay) ​

首次输入延迟，用户首次交互到浏览器响应的时间。

javascript
import { getFID } from 'web-vitals'

getFID(console.log)

// 输出示例
{
  name: 'FID',
  value: 18.5,
  rating: 'good',
  id: 'vital-2'
}

3. CLS (Cumulative Layout Shift) ​

累积布局偏移，页面视觉稳定性指标。

javascript
import { getCLS } from 'web-vitals'

getCLS(console.log)

// 输出示例
{
  name: 'CLS',
  value: 0.12,
  rating: 'needs-improvement',
  id: 'vital-3'
}

4. 指标标准 ​

指标良好需改进差
LCP< 2.5s2.5s-4s> 4s
FID< 100ms100ms-300ms> 300ms
CLS< 0.10.1-0.25> 0.25

二、Performance API ​

1. 基础使用 ​

javascript
// 标记开始
performance.mark('fetch-start')

// 执行操作
await fetch('/api/data')

// 标记结束
performance.mark('fetch-end')

// 测量
performance.measure('fetch', 'fetch-start', 'fetch-end')

// 获取测量结果
const measures = performance.getEntriesByType('measure')
console.log(measures[0].duration)

2. 获取资源 timing ​

javascript
const resources = performance.getEntriesByType('resource')

resources.forEach(resource => {
  console.log({
    name: resource.name,
    duration: resource.duration,
    transferSize: resource.transferSize,
    latency: resource.responseStart - resource.requestStart
  })
})

3. 监听性能事件 ​

javascript
const observer = new PerformanceObserver((list) => {
  list.getEntries().forEach(entry => {
    console.log(entry.name, entry.duration)
  })
})

observer.observe({ entryTypes: ['measure', 'resource'] })

三、Lighthouse ​

1. Chrome DevTools ​

  1. 打开 Chrome DevTools
  2. 切换到 Lighthouse 面板
  3. 点击 "Analyze page load"

2. 命令行 ​

bash
# 安装
npm install -g lighthouse

# 运行
lighthouse https://example.com --output=html --output-path=report.html

3. 报告指标 ​

  • Performance 性能分数
  • Accessibility 可访问性
  • Best Practices 最佳实践
  • SEO 搜索引擎优化
  • PWA 渐进式 Web 应用

四、自定义监控 ​

1. 页面加载时间 ​

javascript
// 首屏渲染时间
window.addEventListener('load', () => {
  const loadTime = performance.timing.loadEventEnd - performance.timing.navigationStart
  console.log('页面加载时间:', loadTime)

  // DOM 构建时间
  const domReady = performance.timing.domContentLoadedEventEnd - performance.timing.navigationStart
  console.log('DOM 完成时间:', domReady)
})

2. 慢交互监控 ​

javascript
let longTask = new PerformanceObserver((list) => {
  list.getEntries().forEach(entry => {
    console.log('长任务:', entry.duration, 'ms')
    // 上报
    reportPerformance({ type: 'longTask', duration: entry.duration })
  })
})

longTask.observe({ entryTypes: ['longtask'] })

3. 错误监控 ​

javascript
// 监听 JS 错误
window.addEventListener('error', (event) => {
  reportPerformance({
    type: 'error',
    message: event.message,
    filename: event.filename,
    lineno: event.lineno
  })
})

// 监听 Promise 拒绝
window.addEventListener('unhandledrejection', (event) => {
  reportPerformance({
    type: 'unhandledrejection',
    reason: event.reason
  })
})

五、上报方案 ​

1. 简单上报 ​

javascript
function reportPerformance(data) {
  const payload = {
    ...data,
    url: window.location.href,
    timestamp: Date.now(),
    userAgent: navigator.userAgent
  }

  // 发送数据
  navigator.sendBeacon('/api/performance', JSON.stringify(payload))
}

2. 批量上报 ​

javascript
const queue = []

function addToQueue(data) {
  queue.push(data)
  if (queue.length >= 10) {
    flushQueue()
  }
}

function flushQueue() {
  if (queue.length === 0) return

  navigator.sendBeacon('/api/performance', JSON.stringify(queue))
  queue.length = 0
}

// 页面离开时上报
window.addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'hidden') {
    flushQueue()
  }
})

七、性能优化建议 ​

1. 定期监控 ​

  • 每次发版前运行 Lighthouse
  • 线上环境持续监控核心指标
  • 关注用户真实体验数据

2. 建立基准 ​

  • 记录优化前的指标
  • 设定优化目标
  • 定期对比

3. 告警机制 ​

javascript
// 设置阈值告警
if (lcp > 2500) {
  alert('LCP 超过阈值')
  notifyTeam({ metric: 'LCP', value: lcp })
}
